# Requirements: 侧边栏重构 + 常用数字员工快捷入口

## 概述

重构桌面 AI 助手面板的左侧导航栏布局：将"设置"按钮改为"系统"弹出菜单，腾出空间放置最多 5 个常用数字员工快捷按钮。同时清理 A2A 群聊相关的冗余入口。

## 需求列表

### 1. 左侧导航栏"设置"按钮改为"系统"横向弹出菜单

- 1.1 将最左侧底部的"设置"按钮文字改为"系统"
- 1.2 点击"系统"按钮后，弹出横向菜单条（向右弹出，不是打开设置面板）
- 1.3 横向菜单条上包含原来的导航项：设置、监控、技能、MCP、八卦、智网
- 1.4 点击菜单条上的某一项后，跳转到对应面板（与原来点击导航栏图标行为一致）
- 1.5 菜单条在点击外部区域时自动关闭
- 1.6 菜单条样式：圆角、阴影、与主题色一致
- 1.7 "关于"按钮保留在"系统"按钮下方，位置不变

### 2. 常用数字员工快捷按钮区域

- 2.1 在 AI 助手按钮下方的分隔条之后、底部"系统"按钮之前的区域，显示常用数字员工按钮
- 2.2 最多显示 5 个常用数字员工
- 2.3 每个按钮显示数字员工的头像/图标 + 名称（缩略）
- 2.4 点击常用数字员工按钮，行为等同于双击数字员工列表中的对应项（调用 `onStartConversation`，打开/激活与该 VE 的对话 Tab）
- 2.5 常用数字员工按钮支持拖动排序（drag-and-drop 调整位置）
- 2.6 当没有设置任何常用数字员工时，该区域不显示（不占空间）
- 2.7 当因授权限制或无数字员工授权导致主界面中间的数字员工列表/历史 Tab 不显示时，常用数字员工按钮区域也同步隐藏
- 2.8 同样条件下，设置面板中的"数字员工"Tab 也隐藏

### 3. 常用数字员工设置（系统设置新增"数字员工"tab）

- 3.1 在系统设置面板中新增"数字员工"tab
- 3.2 该 tab 中显示当前已设置的常用数字员工列表（最多 5 个），支持：
  - 查看当前常用列表
  - 从数字员工列表中添加新的常用
  - 移除已有的常用
  - 拖动调整顺序
- 3.3 数字员工列表来源：复用现有的 `ListVirtualEmployees` Wails binding

### 4. 从数字员工列表右键菜单设为常用

- 4.1 在界面中间的数字员工列表（`VirtualEmployeeTab`）中，每项的右键菜单新增"设为常用"菜单项
- 4.2 如果当前常用数量 < 5，直接添加到常用列表末尾
- 4.3 如果当前常用数量已满 5 个，弹出替换选择器：
  - 显示当前 5 个常用数字员工
  - 用户点击要替换的位置
  - 确认后，新数字员工替换该位置
- 4.4 替换选择器样式：模态弹窗或 popover，显示 5 个位置槽位，已占用的显示名称，点击即替换
- 4.5 如果该数字员工已经在常用列表中，菜单项显示为"已是常用"（灰色不可点击）

### 5. 清理 A2A 群聊入口

- 5.1 从设置面板 tab 列表中移除"A2A 群组"tab（已完成）
- 5.2 从 AI 助手面板标题栏移除 A2A 群聊按钮/下拉菜单（`AssistantGroupDiscussionDropdown`）
- 5.3 底层 A2A 群组讨论 API 逻辑保留（数字员工群聊依赖）

### 6. 数据持久化

- 6.1 常用数字员工列表持久化到 `config.json`（字段名 `favorite_employees`，类型 `string[]`，存储 VE ID）
- 6.2 顺序即为显示顺序
- 6.3 应用启动时从 config 加载常用列表
- 6.4 VE 离线/被删除时，常用按钮仍显示但标记为灰色/不可用状态

## 非功能需求

- 拖动排序使用 HTML5 Drag and Drop API 或轻量库（不引入重型依赖）
- 弹出菜单的动画流畅（CSS transition）
- 常用按钮区域在窗口高度不足时可滚动或自动隐藏溢出项
