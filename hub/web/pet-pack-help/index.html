宠物包（Pet Pack）创建指南

用声明式资源包做出自己的桌面宠物：一个 YAML 清单 + 若干 PNG/WebP 状态图，打成 zip 即可安装。不需要写 JS，也不用改 MaClaw 源码。

1. Pet Pack 是什么

Pet Pack 是放在用户目录下的纯资源包，用来替换/扩展桌面宠物外观：

  • 能做：自定义形象、多状态表情（待机/聆听/思考/说话等）、设置页文案与推荐动效参数。
  • 不能做：不能执行代码、不能注册工具/技能、不能放 JS/HTML/可执行文件。
  • 和 Skill/MCP 插件的区别：插件是能力；Pet Pack 只是皮相（展示数据）。
安装后位置：{MaclawBaseDir}/pet-packs/<id>/（Windows 常见为用户目录下 .maclaw/pet-packs/）。

2. 完整目录结构（必须严格遵守）

推荐在磁盘上先建文件夹，最后再 zip。结构如下：

cool-pet/                      ← 文件夹名建议与 id 一致
├── pet-pack.yaml              ← 【必需】清单，UTF-8 编码
├── preview.png                ← 【推荐】设置页缩略图 256×256
├── README.md                  ← 可选，给人看的说明（会随包安装）
└── native/                    ← 【必需】Windows 桌宠用的状态帧
    ├── idle.png               ← 【必需】待机（figurative 最低要求）
    ├── listening.png          ← 强烈推荐：聆听/ASR
    ├── thinking.png           ← 强烈推荐：思考/Agent
    ├── speaking.png           ← 强烈推荐：说话/TTS
    ├── done.png               ← 可选：任务完成
    ├── alert.png              ← 可选：警告/需确认
    └── quiet.png              ← 可选：勿扰/安静

文件角色说明

路径是否必须作用
pet-pack.yaml必须包身份、状态图映射、变体、动效参数
native/idle.png具象必须默认外观；其它状态缺图时回落 idle
native/listening|thinking|speaking.png推荐对应语音/思考/播报状态更生动
preview.png推荐设置页卡片预览（也可用 idle 代替）
native/done|alert|quiet.png可选完成、告警、勿扰等扩展态
zip 里不要混入 .js、.exe、.html 等文件，安装会直接拒绝。

3. id 与命名规则

  • 清单字段 id 必须匹配：^[a-z][a-z0-9-]{1,63}$
  • 只能：小写字母开头，后接小写字母 / 数字 / 连字符 -。
  • 合法：cool-pet、my-fox、office-bot-01
  • 非法：CoolPet（大写）、1fox（数字开头）、my_pet（下划线）、中文 id
  • 安装后目录名即 id；若与官方 id 冲突（如 clawmate），用户包会覆盖展示但卸载用户副本后仍回官方 bundled。

4. pet-pack.yaml 字段详解

文件必须是 YAML，建议 UTF-8 无 BOM。核心字段：

字段类型说明
schema_versionint固定写 1
idstring包唯一 id（见上）
namestring显示名（英文或通用名）
versionstring建议 semver，如 1.0.0
authorstring作者
tierstringfigurative（具象）/ classic
rendererstringnative-raster=用图片；procedural-fallback=过程式几何
preview / assets.preview路径相对包根的预览图，如 preview.png
assets.nativemap状态名 → 相对路径（见下）
variantslist至少建议有 default 与 classic
motionobject节奏与音高推荐（不覆盖用户音效预设）
labelmap多语言名：en / zh-Hans / zh-Hant
description_i18nmap多语言简介
default_sizeint建议 88（56–120）
tonestringbalanced / compact / developer / focus
face_overlaybool设置页是否叠 CSS 假脸（原生窗忽略）；具象图建议 false

assets.native 状态键

键名必须是小写英文，与运行时状态一致：

  • idle — 待机（必需）
  • listening — 聆听
  • thinking — 思考 / 处理中
  • speaking — 播报 / 说话
  • done — 完成（可选）
  • alert — 告警（可选）
  • quiet — 勿扰（可选）

motion 字段

motion:
  idle_ms: 4000          # 待机动画周期感（参考）
  listening_ms: 1200
  thinking_ms: 1800
  speaking_ms: 950
  amplitude: 0.85        # 0~1，动作幅度
  sound_profile: classic # 仅推荐：classic|bubble|chime|synth|soft
  pitch: 1.0             # 音高倍率；用户所选音效预设始终优先
音效：设置里用户选的「动作音效」预设永远优先；包只提供 pitch 和推荐 profile，不会强行改用户选择。

5. 状态帧怎么画 / 导出

画布与格式

  • 推荐画布 256×256 像素（也可用 512，安装体积会更大）
  • 色彩 sRGB；透明背景（不要白底方块）
  • 格式：PNG 或 WebP（扩展名必须是 .png / .webp）
  • 单帧建议：PNG ≤ 80KB，WebP ≤ 40KB；整包未压缩尽量 ≤ 2MB

构图建议（小尺寸可读）

  • 主体居中，四周留透明边距（约 8–12%），避免贴边被裁切
  • 眼睛、嘴巴在 64–88px 显示时仍要能辨认（对比度够）
  • 各状态主要靠表情/姿态区分，不要只靠文字
  • 配色可参考官方：强调色 indigo #6366F1、深灰眼、浅壳

各状态画什么

状态建议画面
idle中性表情、轻微“活着”感
listening眼睛更亮/身体前倾/天线或耳朵竖起
thinking眼睛半眯、看向一侧、可加思考气泡点
speaking嘴巴张开、面颊微红
done微笑、递出卡片/勾选感
alert严肃、强调色警告环
quiet闭眼或更小存在感

工具建议

  • Figma / Photopea / Aseprite / Photoshop：导出 PNG 透明
  • 可用 AI 出图，再统一裁切到 256 透明底
  • 没有美术时：用纯色圆形身体 + 两点眼睛也能当 MVP 测试安装流程

6. 变体 classic / default

  • default（具象）：使用 native/* 图片，这是自制包的主目标。
  • classic（经典）：忽略图片，用客户端内置过程式几何绘制（兼容回落）。

清单里建议两个变体都写上：用户可在设置里「画质风格」切换。你的图主要服务于 default。

7. 从零构建（推荐流程）

  1. 定 id 与角色 想好包 id（如 office-fox）和人设（办公狐狸、极简机器人…）。
  2. 建文件夹 创建 office-fox/ 与子目录 native/。
  3. 画 4 张核心状态图 至少 idle / listening / thinking / speaking，256×256 透明 PNG。文件名与 yaml 中路径一致。
  4. 写 pet-pack.yaml 复制下方「最小可用示例」，改 id、name、label、路径；确认 assets.native 与文件真实存在。
  5. 自检文件名 Windows 上注意扩展名是 .png 不是 .PNG.png；路径用正斜杠 native/idle.png。
  6. 打包 zip 见下一节。推荐 zip 内是 office-fox/pet-pack.yaml 这种带一层目录的结构。
  7. 在 MaClaw 安装 设置 → 桌面宠物 →「选择 Zip 安装」→ 切到「具象」→ 启用桌面宠物查看效果。
  8. 按验收清单微调 小尺寸五官、缺状态回落、勿扰模式等。

8. 打包与安装

正确的 zip 结构（两种都行）

# 方式 A（推荐）：带一层目录
cool-pet.zip
└── cool-pet/
    ├── pet-pack.yaml
    ├── preview.png
    └── native/...

# 方式 B：清单在 zip 根
cool-pet.zip
├── pet-pack.yaml
├── preview.png
└── native/...

Windows 打包示例

  1. 在资源管理器中进入 cool-pet 的上一级。
  2. 右键文件夹 cool-pet → 发送到 → 压缩(zipped)文件夹。
  3. 不要把整个「桌面」或含无关文件的父目录打进去。

PowerShell

Compress-Archive -Path .\cool-pet\* -DestinationPath .\cool-pet.zip -Force
# 若希望 zip 内带 cool-pet/ 目录：
Compress-Archive -Path .\cool-pet -DestinationPath .\cool-pet.zip -Force

客户端安装

  1. 打开 MaClaw → 设置 → 桌面宠物
  2. 点「选择 Zip 安装」
  3. 安装成功后形象列表出现新 id；画质选「具象」
  4. 打开「启用桌面宠物」看桌面分层窗效果

9. 安全限制（安装器会强制）

  • 最多 64 个文件；单文件 ≤ 512 KiB；未压缩合计 ≤ 2 MiB
  • 压缩比过高（zip bomb）会拒绝
  • 路径禁止 .. 逃逸；禁止绝对路径
  • 允许扩展名：.webp .png .yaml .yml .json .txt .md（SVG 会扫描危险内容，自制建议只用 PNG/WebP）
  • 禁止：.js .mjs .cjs .wasm .exe .dll .html .bat .cmd .ps1 等

10. 最小可用示例（可复制）

建目录 cool-pet/，放入四张图后使用：

schema_version: 1
id: cool-pet
name: Cool Pet
version: 1.0.0
author: Your Name
tier: figurative
renderer: native-raster
face_overlay: false
preview: preview.png
default_size: 88
tone: balanced
label:
  en: Cool Pet
  zh-Hans: 酷酷爪
  zh-Hant: 酷酷爪
description_i18n:
  en: A friendly workbench companion you made yourself.
  zh-Hans: 你自己做的友好工作台伙伴。
  zh-Hant: 你自己做的友好工作台夥伴。
assets:
  preview: preview.png
  native:
    idle: native/idle.png
    listening: native/listening.png
    thinking: native/thinking.png
    speaking: native/speaking.png
variants:
  - id: default
    tier: figurative
    renderer: native-raster
    face_overlay: false
    assets:
      native:
        idle: native/idle.png
        listening: native/listening.png
        thinking: native/thinking.png
        speaking: native/speaking.png
  - id: classic
    tier: classic
    renderer: procedural-fallback
    face_overlay: true
motion:
  idle_ms: 4000
  listening_ms: 1200
  thinking_ms: 1800
  speaking_ms: 950
  amplitude: 0.85
  sound_profile: classic
  pitch: 1.0
capabilities:
  supports_done_state: false
  supports_alert_state: false

若暂时只有一张图：四份状态都指向 native/idle.png 也能先装上，再慢慢补表情。

11. 验收清单（装上前勾一遍）

  • □ id 符合正则，与文件夹名一致
  • □ 存在 pet-pack.yaml，UTF-8，缩进正确（空格，不是 Tab）
  • □ 至少有 native/idle.png 且 yaml 路径能对上
  • □ 没有 JS/可执行文件
  • □ zip 体积合理；解压后目录结构正确
  • □ 设置页能看到名字（label）
  • □ 画质「具象」下桌宠不是过程式默认爪（说明帧加载成功）
  • □ 触发聆听/思考时若有对应帧会切换（需客户端状态桥）

12. 常见问题

安装失败 forbidden extension

删掉 zip 里非允许扩展名文件后重打。

安装成功但还是抽象几何爪

设置画质风格为「具象」；确认 renderer: native-raster 且 idle 图可解码。

yaml 改了不生效

重新 zip 安装会覆盖同 id 用户目录；或关掉再开设置刷新列表。

可以放 GIF/MP4 吗？

当前 MVP 仅静态 PNG/WebP 帧，不支持动画视频。

如何卸载

在设置 → 桌面宠物中选中用户包，点「卸载当前用户包」。官方 bundled 形象不能卸。也可手动删除 {MaclawBaseDir}/pet-packs/<id>/。

Pet Pack Creation Guide

Ship your own desktop pet as a declarative resource pack: one YAML manifest + PNG/WebP state frames, zipped for install. No JavaScript, no MaClaw source changes.

1. What is a Pet Pack

A Pet Pack is a data-only package under the user pet-packs directory that changes how the desktop pet looks:

  • Can: custom character art, multi-state expressions, settings labels, motion/pitch hints.
  • Cannot: run code, register tools/skills, include JS/HTML/executables.
  • vs Skill/MCP plugins: plugins are capabilities; Pet Packs are skins only.
Install location: {MaclawBaseDir}/pet-packs/<id>/ (often .maclaw/pet-packs/ under the user profile on Windows).

2. Full directory layout (follow exactly)

cool-pet/                      ← folder name should match id
├── pet-pack.yaml              ← REQUIRED manifest (UTF-8)
├── preview.png                ← recommended 256×256 settings thumb
├── README.md                  ← optional human notes
└── native/                    ← REQUIRED state frames for Windows pet
    ├── idle.png               ← REQUIRED for figurative packs
    ├── listening.png          ← recommended
    ├── thinking.png           ← recommended
    ├── speaking.png           ← recommended
    ├── done.png               ← optional
    ├── alert.png              ← optional
    └── quiet.png              ← optional
PathRequired?Role
pet-pack.yamlYesIdentity, asset map, variants, motion
native/idle.pngYes (figurative)Default look; fallback for missing states
native/listening|thinking|speaking.pngStrongly recommendedASR / agent / TTS feedback
preview.pngRecommendedSettings card thumbnail
Do not put .js, .exe, .html, etc. in the zip — install will reject them.

3. id rules

  • Must match ^[a-z][a-z0-9-]{1,63}$
  • Lowercase letter first; then lowercase letters, digits, hyphens only
  • Good: cool-pet, my-fox, office-bot-01
  • Bad: CoolPet, 1fox, my_pet, non-ASCII ids

5. Drawing / exporting frames

  • Canvas 256×256 (or 512), sRGB, transparent background
  • PNG or WebP only; keep frames small (PNG ≤ 80KB, WebP ≤ 40KB recommended)
  • Center the character; leave transparent padding; keep face readable at 64–88px
  • Differentiate states by expression/pose, not text
StateArt hint
idleNeutral, alive
listeningAlert eyes, lean in
thinkingHalf-closed eyes, looking aside
speakingOpen mouth, cheeks
doneSmile / checkmark energy
alertSerious warning ring
quietClosed eyes, low presence

Tools: Figma, Photopea, Aseprite, Photoshop, or AI image tools then crop to 256 transparent PNG. Solid color body + two eyes is enough to test install first.

6. classic / default

  • default (figurative): uses native/* images — your main target.
  • classic: procedural geometry fallback (ignores your frames).

Ship both variants in YAML so users can switch Visual Tier in Settings.

7. Build from scratch

  1. Pick an id & character e.g. office-fox.
  2. Create folders office-fox/ and office-fox/native/.
  3. Draw 4 core frames idle/listening/thinking/speaking as 256 transparent PNGs.
  4. Write pet-pack.yaml from the minimal example; paths must match files.
  5. Self-check extensions and forward slashes native/idle.png.
  6. Zip (prefer one root folder inside the archive).
  7. Install in MaClaw Settings → Desktop Pet → Choose Zip → Visual Tier Figurative → Enable pet.
  8. Polish using the checklist.

8. Zip & install

# Preferred: folder at zip root
cool-pet.zip
└── cool-pet/
    ├── pet-pack.yaml
    ├── preview.png
    └── native/...

# Also OK: manifest at zip root

└── native/...

Windows

Right-click the cool-pet folder → Send to → Compressed (zipped) folder. Or PowerShell:

Compress-Archive -Path .\cool-pet -DestinationPath .\cool-pet.zip -Force

In MaClaw

  1. Settings → Desktop Pet
  2. Choose Zip to Install
  3. Select the pack; set Visual Tier to Figurative
  4. Enable Desktop Pet and verify the layered window

9. Security limits (enforced)

  • ≤ 64 files; ≤ 512 KiB per file; ≤ 2 MiB total uncompressed
  • Zip-bomb ratio rejected; no .. path escape
  • Allowed: .webp .png .yaml .yml .json .txt .md (prefer raster for third-party)
  • Denied: .js .exe .html .dll .bat .ps1 …

11. Pre-install checklist

  • □ id matches regex and folder name
  • □ pet-pack.yaml is UTF-8 YAML with spaces (not tabs)
  • □ native/idle.png exists and paths match
  • □ no executable/JS files
  • □ zip structure correct when unzipped
  • □ label shows in Settings
  • □ Figurative tier shows your art (not procedural geometry)

12. FAQ

Install fails with forbidden extension

Remove disallowed files and re-zip.

Installed but still abstract geometry

Set Visual Tier to Figurative; ensure native-raster and a valid idle image.

GIF / MP4?

Not supported in MVP — static PNG/WebP frames only.

Uninstall

In Settings → Desktop Pet, select a User pack and click Uninstall selected user pack. Official bundled skins cannot be removed. Or delete {MaclawBaseDir}/pet-packs/<id>/ manually.
