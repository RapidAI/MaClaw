Use MaClaw official Credits

使用 MaClaw 官方额度

MaClaw албан ёсны Credits ашиглах

Official Credits keep authorized users on MaClaw's managed provider directly inside the app, with usage and remaining Credits visible in your authorization status.

官方额度可让已授权用户在应用内直接使用 MaClaw 托管服务商，并在授权状态中清楚展示用量与剩余额度。

Албан ёсны Credits нь зөвшөөрөгдсөн хэрэглэгчийг апп дотор MaClaw-ийн удирдлагатай нийлүүлэгч дээр шууд байлгаж, хэрэглээ болон үлдэгдэл Credits-ийг зөвшөөрлийн төлөвт харуулна.

  • Managed provider access托管服务商访问Удирдлагатай нийлүүлэгчийн хандалт
  • Credits tracked in your authorization status额度会显示在授权状态中Credits зөвшөөрлийн төлөвт харагдана
  • Best path when you want MaClaw to manage provider keys适合希望由 MaClaw 托管服务商密钥的用户MaClaw нийлүүлэгчийн түлхүүрийг удирдахад тохиромжтой

Use your own LLM provider

添加自己的大模型服务商

Өөрийн LLM нийлүүлэгч ашиглах

Add a provider API key in MaClaw settings when you want billing and provider credentials to stay under your own account.

如果你希望账单和服务商密钥都由自己的账户管理，可以在 MaClaw 设置中添加服务商密钥作为备用路径。

Төлбөр болон нийлүүлэгчийн түлхүүрийг өөрийн дансаар удирдахыг хүсвэл MaClaw-ийн тохиргоонд нийлүүлэгчийн API түлхүүр нэмнэ.

  • Works immediately after configuration配置完成后即可使用Тохируулсны дараа шууд ажиллана
  • Provider billing stays under your own account服务商账单由你自己的账户管理Нийлүүлэгчийн төлбөр өөрийн дансанд үлдэнэ
  • Useful as a fallback when official Credits are not enough适合作为官方额度不足时的补充通道Албан ёсны Credits хүрэлцэхгүй үед нөөц зам болно
