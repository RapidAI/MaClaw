## 2. 配色方案

### 主色板

| 角色 | 色名 | 色值 | 用途 | 示例 |
|------|------|------|------|------|
| **主色** | 科技深蓝 | `#0A1628` | 封面背景、章节分隔页背景、深色区块 | ██████ |
| **主色辅助** | 品牌蓝 | `#1A6FDB` | 标题栏、按钮、图标主色、数据图表主色 | ██████ |
| **辅色** | 天际蓝 | `#3B9BFF` | 副标题、连接线、装饰元素 | ██████ |
| **辅色** | 冰蓝渐变 | `#00D4FF → #1A6FDB` | 渐变背景条、科技光效、数据流线条 | ██████→██████ |
| **强调色** | 活力橙 | `#FF6B35` | 核心数据高亮、CTA按钮、关键指标 | ██████ |
| **强调色** | 安全绿 | `#00C48C` | 正向指标、增长数据、成功标识 | ██████ |
| **中性色** | 云白 | `#FFFFFF` | 正文文字（深色背景上）、卡片背景 | ██████ |
| **中性色** | 浅灰蓝 | `#C8D6E5` | 次要文字、辅助说明、边框线 | ██████ |
| **中性色** | 深灰 | `#2D3436` | 正文文字（浅色背景上） | ██████ |

### 配色规则

- **深色页**（封面/章节页/结尾页）：背景 `#0A1628`，文字 `#FFFFFF`
- **内容页**：背景 `#FFFFFF` 或极浅灰 `#F8FAFC`，标题栏用 `#1A6FDB` 深蓝渐变条
- **数据高亮原则**：每页最多1-2个数据用 `#FF6B35` 强调，避免色彩过多
- **图表配色**：统一使用蓝色系渐变（`#1A6FDB → #00D4FF`），对比项用 `#FF6B35`

## 4. 版式规则

### 页面布局网格

```
┌─────────────────────────────────────────────┐
│  ← 左边距 60px →                    右边距 60px →│
│  ┌─────────────────────────────────────────┐  │
│  │  标题栏（高80px）                         │  │
│  │  标题文字 + 装饰线条                       │  │
│  ├─────────────────────────────────────────┤  │
│  │                                          │  │
│  │  内容区域（主体）                          │  │
│  │  左右留白 ≥ 60px                         │  │
│  │                                          │  │
│  │                                          │  │
│  ├─────────────────────────────────────────┤  │
│  │  页脚（高40px）                           │  │
│  │  页码 + 公司Logo小标 + Slogan             │  │
│  └─────────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

### 核心版式参数

| 参数 | 规范 |
|------|------|
| **页面比例** | 16:9（标准宽屏） |
| **安全边距** | 四边 ≥ 60px |
| **标题区域** | 顶部80px，含品牌蓝色渐变底条 |
| **内容区域** | 居中，左右对齐均可（中文左对齐优先） |
| **页脚** | 底部40px，居中放页码，右侧放江民Logo小标 |
| **留白比例** | 内容占比 ≤ 60%，留白 ≥ 40% |
| **卡片间距** | 统一使用24px间距 |
| **图文比例** | 图片/图表占比 ≥ 40%，避免纯文字墙 |

### 常用版式模板

| 版式类型 | 适用页面 | 说明 |
|----------|----------|------|
| **全屏图+文字叠加** | P1封面、P20结尾 | 大图/深色渐变背景 + 居中大标题 |
| **标题+左右分栏** | P2-P3品牌故事、P5研发体系 | 左文右图或左图右文 |
| **标题+三/四列卡片** | P6引擎展示、P9产品全景 | 等宽卡片排列 |
| **标题+大数字+说明** | P14客户规模 | 超大数字居中 + 下方行业标签 |
| **标题+时间轴** | P3品牌里程碑 | 横向/纵向时间线 |
| **标题+左右对比** | P19为什么选择江民 | 左侧痛点/右侧方案 |

## 5. 图表风格

### 通用图表规范

| 参数 | 规范 |
|------|------|
| **图表配色** | 主序列用蓝色渐变 `#1A6FDB → #3B9BFF`，对比序列用 `#FF6B35` |
| **数据标签** | 12pt，颜色 `#2D3436`，关键数据加粗 + 强调色 |
| **网格线** | 浅灰 `#E8ECF1`，虚线，仅在需要时显示 |
| **图例** | 10-12pt，位于图表下方或右侧 |
| **图表标题** | 14pt Bold，颜色 `#2D3436` |

### 分图表样式

| 图表类型 | 样式规范 |
|----------|----------|
| **柱状图** | 圆角柱体（r=4px），蓝色渐变填充，间距 = 柱宽的50% |
| **折线图** | 线宽2.5px，数据点用圆点（r=5px），渐变面积填充（透明度20%） |
| **饼图/环形图** | 环形（内径55%），蓝色系为主+橙色强调，标签引导线 |
| **架构图** | 圆角矩形（r=8px），蓝色填充+白色文字，箭头用天际蓝 |
| **时间轴** | 纵向排列，左侧时间节点圆点+连接线，右侧事件卡片 |
| **图标矩阵** | 统一使用线性图标风格，颜色 `#1A6FDB`，尺寸48×48px |

## 6. 品牌元素

| 元素 | 规范 |
|------|------|
| **公司Logo** | 封面居中/居上展示，内容页右上角小标（宽120px），页脚右侧（宽80px） |
| **Slogan** | "终端安全守护者"——封面副标题位置、页脚左侧小字 |
| **品牌图标** | 盾牌/锁图标作为安全象征，用于封面、章节页装饰 |
| **科技装饰元素** | 流动线条、数据粒子、网格背景——用于深色页面的氛围渲染 |
| **产品品牌** | "赤豹"系列使用统一的豹头图标标识 |
