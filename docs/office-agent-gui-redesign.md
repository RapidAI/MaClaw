# MaClaw 办公 Agent GUI 重构设计文档

## 1. 设计目标

将 MaClaw 从项目型、工具型界面重构为面向办公任务的 AI Agent 工作台。界面需要现代、专业、简洁，保留现有任务、通知、小程序、AI 专家、数字员工、模型、Token、套餐和点卡等能力。

核心原则：

- 任务优先：用户进入软件后直接创建或继续办公任务。
- 统一工作区：启动、执行、完成、历史使用同一套布局。
- 信息分层：常用操作突出，状态信息收纳，复杂配置按需展开。
- 保留能力：只调整组织方式，不删除已有业务功能。
- 轻量留白：减少边框、分割线和重复标题，避免拥挤。

## 2. 总体布局

采用三层结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏：页面标题       当前任务/状态        搜索 通知 账户   │
├──────────┬──────────────────┬───────────────────────────────┤
│ 主导航   │ 任务导航          │ 主工作区                      │
│ 56–72px  │ 220–280px         │ 自适应                         │
│          │                  │                               │
│ 工作台   │ 新建任务          │ 启动页 / 任务执行页 / 历史页    │
│ 任务     │ 进行中            │                               │
│ 通知     │ 待处理            │                               │
│ 小程序   │ 已完成            │                               │
│ AI专家   │ 最近任务          │                               │
│ 数字员工 │                  │                               │
│ 文件     │                  │                               │
│ 设置     │                  │                               │
├──────────┴──────────────────┴───────────────────────────────┤
│ 底部状态栏：在线状态  当前模型  Token  套餐/点卡  帮助       │
└──────────────────────────────────────────────────────────────┘
```

### 2.1 主导航

保留并重新组织现有入口：

- 工作台
- 任务
- 通知中心
- 小程序
- AI 专家
- 数字员工
- 文件
- 系统设置
- 关于与帮助

当前选中项使用浅色背景、主题色图标和左侧指示条。导航默认只显示图标与短标签，支持收窄为图标模式。

### 2.2 任务导航

任务导航是办公任务列表，不再使用项目、目录、Git、分支等表达。

分组：

- 新建任务
- 进行中
- 待处理
- 已完成
- 最近任务

任务卡片显示：任务标题、状态、最近更新时间、关联数字员工或专家、输出文件数量。长标题最多两行，避免列表拥挤。

## 3. 启动页

### 3.1 页面内容

启动页是用户打开软件后的默认工作台：

1. 顶部显示问候语和当前日期。
2. 中央显示主任务输入框：`你想完成什么办公任务？`
3. 输入框支持附件、语音、选择 AI 专家、选择数字员工和发送。
4. 输入框下方显示常用任务卡片：
   - 写一封邮件
   - 整理会议纪要
   - 生成工作汇报
   - 分析 Excel 数据
   - 制作演示文稿
   - 整理文件
5. 下方显示最近任务，支持继续、复制和删除。
6. 首次启动时显示环境准备状态卡片，不显示空白等待页。

### 3.2 启动页状态

- 空闲：显示任务输入和快捷任务。
- 正在准备：显示环境检查卡片和进度。
- 准备完成：自动进入空闲状态。
- 准备失败：显示失败原因、重试和打开日志目录按钮。

## 4. 任务运行页

### 4.1 顶部区域

- 任务名称
- 当前状态：准备中、执行中、需要确认、已完成、失败
- 暂停、继续、停止按钮
- 更多操作：重命名、复制任务、导出记录

### 4.2 主内容区

主内容采用对话与执行时间线结合的形式：

- 用户任务目标卡片
- AI 计划与执行步骤
- 每个步骤显示状态、耗时和简短结果
- 需要用户确认时显示明确的确认卡片
- 生成的文档、表格、图片等使用结果卡片展示
- 支持展开详细日志，但默认收起技术细节

### 4.3 右侧摘要区

右侧仅保留必要信息：

- 当前任务摘要
- 已完成步骤数量
- 输出文件
- 相关专家或数字员工

无内容时自动隐藏，避免大面积空白。

### 4.4 底部输入区

统一使用任务输入框，支持：

- 追加指令
- 上传附件
- 语音输入
- 选择模型
- 选择专家或数字员工
- 发送与快捷键提示

## 5. 历史任务页

历史任务以任务为中心，而不是以会话 Tab 为中心。

功能：

- 按今天、昨天、更早分组
- 搜索任务标题和内容
- 按状态筛选
- 继续任务
- 查看输出文件
- 复制任务
- 删除任务

打开历史任务后进入统一任务运行工作区，避免切换到另一套页面。

## 6. 通知中心

通知中心用于展示：

- 任务完成
- 需要确认
- 任务失败
- 文件生成完成
- 系统更新
- 套餐和点卡提醒

通知使用时间线卡片，支持全部已读、筛选和跳转到对应任务。

## 7. 小程序、AI 专家与数字员工

### 小程序

使用网格卡片展示可用办公能力。每张卡片包含图标、名称、用途和最近使用时间。点击后可以直接创建任务。

### AI 专家

使用专家卡片展示能力标签，例如写作、分析、设计、翻译、会议和数据处理。保留收藏和搜索功能。

### 数字员工

保留现有头像入口。头像卡片显示名称、职责、在线状态和最近任务。点击后直接打开该数字员工的任务对话。

## 8. 状态区设计

底部状态栏保留现有状态信息，但采用紧凑卡片：

- 连接状态：在线 / 离线 / 连接中
- 当前模型
- 本次任务 Token
- 今日 Token 消费
- 套餐名称
- 剩余点卡或额度
- 后台任务数量

详细计费信息通过点击展开，不在主界面堆叠长文本。

## 9. 环境检测与安装页

环境准备页沿用主工作区布局：

```text
准备 MaClaw 工作环境

✓ 检查网络连接
✓ 检查 AI 服务
◌ 准备办公能力
○ 初始化本地文件能力

[重新检查]                         [查看日志]
```

要求：

- 使用步骤卡片，不显示技术日志作为主内容。
- 日志默认折叠，保留“查看详细日志”。
- 安装失败时给出可读的解决建议。
- 完成后自动进入启动页。

## 10. 暗色主题

暗色主题使用深灰蓝背景，避免纯黑：

- 页面背景：`#111827`
- 卡片背景：`#1F2937`
- 次级卡片：`#243244`
- 主文字：`#F3F4F6`
- 次级文字：`#9CA3AF`
- 边框：`#374151`
- 主题色：`#60A5FA`
- 成功色：`#34D399`
- 警告色：`#FBBF24`
- 错误色：`#F87171`

浅色主题保持白色卡片、浅灰背景和蓝色强调色。两套主题的组件结构完全一致。

## 11. 组件拆分建议

- `OfficeAgentShell`：统一应用壳层
- `PrimaryNavRail`：主导航
- `TaskNavigationPane`：任务导航和任务列表
- `OfficeStatusBar`：模型、Token、套餐和连接状态
- `AgentWelcomePage`：启动页
- `AgentTaskWorkspace`：任务运行页
- `TaskTimeline`：执行时间线
- `TaskResultCard`：输出结果
- `TaskHistoryPage`：历史任务
- `NotificationCenterPage`：通知中心
- `MiniProgramsPage`：小程序
- `ExpertsPage`：AI 专家
- `DigitalEmployeesPage`：数字员工
- `EnvironmentSetupPage`：环境检测与安装

## 12. 功能保留清单

以下功能必须继续可用：

- 新建、重命名、继续、暂停、停止和删除任务
- 任务状态和后台任务数量
- 通知中心
- 小程序
- AI 专家
- 数字员工头像与对话
- 文件上传和生成文件下载
- 语音输入和录音
- 模型选择
- Token 消费显示
- 套餐、点卡和额度显示
- 深色/浅色主题
- 环境检测、安装和日志查看
- 系统设置和帮助

本版本完全移除外部编程工具的配置、管理和调度入口，包括 Codex、Claude Code 等，不影响办公 Agent 的任务执行能力。

## 13. 验收标准

- 启动后默认进入新的办公 Agent 启动页。
- 启动、任务执行、历史任务和通知中心使用统一主壳层。
- 页面不出现项目目录、Git 分支、外部编程工具配置等项目型元素。
- 左侧导航仍可访问小程序、AI 专家和数字员工。
- Token、套餐、点卡和在线状态仍可查看。
- 任务运行中可看到清晰的步骤进度和结果文件。
- 空状态不出现大面积无意义空白。
- 浅色和暗色主题均通过视觉检查。
- 使用 `build_win.bat` 完成完整构建，前端 TypeScript 检查和运行时启动验证通过。
