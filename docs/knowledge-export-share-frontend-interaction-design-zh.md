# 知识库导出与分享前端交互设计

## 目标

本文档细化知识库弹窗中的 `导出` 与增强后的 `导入` 交互，供前端开发直接落地。

设计目标：

- 保持现有知识库弹窗结构稳定
- 新增能力尽量贴近现有交互语言
- 把“本地导出、发布到 Hub、查看分享、按知识 ID / 链接导入”串成一条连续体验
- 降低高风险操作误触，尤其是整库替换导入

## 入口与信息架构

知识库弹窗一级 tab 建议为：

- `总览`
- `导入`
- `导出`
- `检索`
- `来源`
- `质量`

本次重点变更：

- 新增 `导出`
- 扩展 `导入`

## 导出 Tab 信息架构

`导出` tab 分为三段，自上而下排列：

1. `本地导出`
2. `发布到 Hub`
3. `已分享`

右上角固定动作：

- `查看分享`

行为：

- 打开默认浏览器
- 跳转到 Hub 的“我的知识导出”页面

## 导出 Tab 页面骨架

建议结构：

```text
导出
说明文案
                                              [查看分享]

+------------------------------------------------------+
| 本地导出                                             |
| 导出范围  导出格式  是否脱敏  输出位置              |
| [导出] [导出并打开文件夹]                            |
+------------------------------------------------------+

+------------------------------------------------------+
| 发布到 Hub                                           |
| 标题  说明  标签  可见范围  指定用户列表             |
| [发布到 Hub]                                         |
| 发布结果区                                           |
+------------------------------------------------------+

+------------------------------------------------------+
| 已分享                                               |
| 最近知识条目列表                                     |
+------------------------------------------------------+
```

## 导出 Tab 文案建议

顶部说明文案建议：

- 中文
  - `将本地知识库导出为可交换知识包，或发布到 Hub 供他人和 agent 使用。`
- 英文
  - `Export local knowledge as a portable package, or publish it to Hub for people and agents.`

## 本地导出区

### 表单字段

- `导出范围`
  - 单选
  - `全部知识库`
  - `当前筛选结果`
  - `指定来源`
- `导出格式`
  - 单选
  - `知识包 (.mckb.zip)` 默认
  - `Snapshot JSONL` 高级选项
- `是否脱敏`
  - 开关
- `输出位置`
  - 只读输入框 + `选择位置`

### 当选择“指定来源”时

出现附加输入：

- `来源 ID`
- `从当前列表选择`

支持两种方式：

- 手填 source ID
- 从“来源”tab 或当前筛选结果中勾选带入

### 操作按钮

- `导出`
- `导出并打开文件夹`

按钮状态：

- 表单未完整时禁用
- 执行中显示 loading

### 成功态

导出成功后，在本地导出区下方展示结果卡：

- `导出成功`
- 文件路径
- 来源数
- 节点数
- 卡片数
- 事实数
- 文件大小

附加动作：

- `发布到 Hub`
- `打开文件夹`
- `复制路径`

### 失败态

错误显示在本区底部，不全局打断：

- 路径不可写
- 磁盘空间不足
- 导出目标为空
- 包生成失败

建议错误样式：

- 红色边框提示框
- 保留原表单值
- 支持直接重试

## 发布到 Hub 区

### 依赖关系

此区默认要求“已有最近一次本地导出结果”。

若尚未导出：

- 区块可见但禁用
- 提示文案：
  - `请先完成本地导出，再发布到 Hub。`

### 表单字段

- `标题`
  - 默认带入最近一次导出文件名或导出时间
- `说明`
  - 多行文本
  - 必填，作为分享页、Hub 浏览和后台知识管理的主要展示内容
- `标签`
  - 可输入多个
- `可见范围`
  - 下拉或单选
  - `全网公开`
  - `本 Hub 公开`
  - `本租户公开`
  - `指定用户可见`
- `指定用户列表`
  - 仅在 `指定用户可见` 时显示
- `允许再次导出`
  - 开关
- `脱敏发布`
  - 开关

### 可见范围交互规则

- `全网公开`
  - 显示提示：
    - `任何可访问公开知识的 Hub 用户都可能导入此知识。`
- `本 Hub 公开`
  - 显示提示：
    - `仅当前 Hub 用户可浏览和导入。`
- `本租户公开`
  - 显示提示：
    - `仅当前租户用户可浏览和导入。`
- `指定用户可见`
  - 必填指定用户

### 操作按钮

- `发布到 Hub`

发布前校验：

- 必须存在最近本地导出结果
- 标题不能为空
- 说明不能为空
- 指定用户模式下必须至少有 1 个用户

### 发布成功态

在本区显示结果卡：

- `发布成功`
- 知识 ID
- 分享链接
- 当前可见范围

动作按钮：

- `复制知识 ID`
- `复制分享链接`
- `打开分享页`
- `查看分享`

### 发布失败态

常见错误：

- Hub 未登录
- Hub 不可达
- 权限不足
- 标题重复策略冲突
- 上传包失败

展示方式：

- 就地错误提示
- 如果是登录态问题，给出：
  - `前往 Hub 登录`

## 已分享区

### 列表字段

- 标题
- 知识 ID
- 说明摘要
- 可见范围
- 更新时间
- 来源数量
- 导入次数
- 状态

### 每项动作

- `复制知识 ID`
- `复制分享链接`
- `打开分享页`
- `编辑说明`
- `删除分享`

### 列表为空态

- `还没有已分享的知识条目。先导出并发布到 Hub。`

### 删除分享交互

点击 `删除分享` 后：

- 打开确认弹窗
- 文案建议：
  - `删除后，分享链接将不可再导入，但不会删除你本地知识库中的内容。`

按钮：

- `取消`
- `删除分享`

## 导入 Tab 扩展设计

`导入` tab 保留现有文本、URL、文件、目录和抓取导入区域，同时在其下方增加两块：

1. `导入知识包`
2. `从 Hub 导入`

## 导入知识包区

### 表单字段

- `选择知识包`
- `预检模式`
  - 开关
- `导入策略`
  - `合并导入`
  - `仅新增`
  - `覆盖冲突项`
  - `整库替换`
- `失败策略`
  - `遇错继续`
  - `遇错终止`
- `创建安全备份`
  - 开关

### 风险提示

当选择 `整库替换` 时：

- 出现高亮风险框
- 文案建议：
  - `整库替换会清空当前知识库再导入新包。建议先做安全备份。`

### 预检结果区

当开启预检或用户点击 `预检` 后，展示：

- 记录数
- 预计导入数
- 冲突数
- 缺失引用数
- 仅引用来源数
- 缺失附件数

附加提示：

- `该知识包包含仅引用来源，导入后部分原文可能不可恢复。`

### 操作按钮

- `预检`
- `开始导入`

## 从 Hub 导入区

### 表单字段

- `知识 ID 或分享链接`
- `解析`

### 解析结果卡

成功解析后展示：

- 标题
- 说明
- 所属 Hub
- 可见范围
- 是否可导入
- 快照版本
- 来源数 / 卡片数 / 事实数

如果不可导入：

- 显示原因
- 不展示导入按钮

### 导入策略

与本地知识包导入保持一致：

- `合并导入`
- `仅新增`
- `覆盖冲突项`
- `整库替换`

### 操作按钮

- `导入到本地知识库`

路径：

```text

```


### 未登录态

展示：

### 无权限态

展示：

- `你没有查看或导入此知识条目的权限。`

### 已删除态

展示：

- `该知识条目已删除或已下架。`

## Hub 左侧 Tab：知识管理

Hub 后台左侧导航新增独立一级 tab：`知识管理`，用于管理员治理所有用户发布的分享知识。

导航规则：

- `知识管理` 显示在 Hub 后台左侧导航中
- 与用户、租户、应用、审计等后台管理入口同级
- Hub 管理员和租户管理员可见
- 不是“我的知识导出”的子页面，也不是普通用户知识页里的入口

权限边界：

- Hub 管理员看到全 Hub 所有租户、所有用户分享的知识
- 租户管理员只看到自己租户下用户分享的知识
- 普通用户不可见

路径建议：

```text
/admin/knowledge/exports
```

### 页面目标

- 列出 Hub 上所有用户发布的分享知识
- 按用户筛选
- 按发布时间、更新时间、访问量、导入量排序
- 每页 50 条
- 管理员可强制删除不再允许分享的知识条目
- 后台只查看知识描述和管理元数据，不查看知识包正文

### 列表字段

- 知识 ID
- 标题
- 知识描述
- 发布用户
- 所属租户
- 可见范围
- 标签
- 发布时间
- 更新时间
- 访问量
- 导入量
- 状态

### 筛选和排序

筛选：

- 用户
- 租户
  - Hub 管理员可用
  - 租户管理员固定为自己租户，不展示跨租户选择
- 状态
- 可见范围

排序：

- 按发布时间倒序
- 按更新时间倒序
- 按访问量倒序
- 按导入量倒序

分页：

- 每页 50 条
- 支持下一页 / 上一页

### 强制删除交互

每条记录提供 `强制删除` 动作。

点击后打开确认弹窗：

- 展示知识 ID、标题、发布用户
- 必须填写删除原因
- 明确提示：
  - `强制删除会让分享链接失效，但不会删除发布者本地知识库。`

按钮：

- `取消`
- `强制删除`

删除成功后：

- 该条状态变为 `已删除`
- 分享链接访问返回已删除态
- 列表保留审计可见信息

权限限制：

- Hub 管理员可强制删除任意租户的分享知识
- 租户管理员只能强制删除自己租户内的分享知识

## 交互一致性要求

- `复制知识 ID` 和 `复制分享链接` 在导出成功卡、已分享列表、分享详情页三处都要保持一致
- `整库替换` 的风险提示在本地包导入和 Hub 导入两处保持一致
- `查看分享` 永远跳到“我的知识导出”页，不跳随机详情页
- 用户分享知识时，`说明` 必填
- Hub 后台知识管理只展示描述和管理元数据，不展示知识正文

## 前端状态建议

建议维护以下关键状态：

- `latestExportResult`
- `latestPublishedEntry`
- `mySharedEntries`
- `shareResolveResult`
- `packageImportPreview`
- `packageImportRunning`
- `hubImportRunning`

## 前端实现优先级

1. `导出` tab 页面骨架和本地导出结果卡
2. `发布到 Hub` 区和成功结果卡
3. `已分享` 列表
4. `导入知识包` 区
5. `从 Hub 导入` 区
6. 分享详情页

## 验收要点

- 用户能在一个弹窗里完成“导出 -> 发布 -> 复制链接”
- 用户能从分享链接或知识 ID 预览后导入
- 高风险操作有明确警示
- 空态、失败态、成功态都不让用户迷路
