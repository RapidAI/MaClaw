# 应用面板操作区与审批实例管理重整

## 背景与目标

应用面板左侧原本只有搜索、分类筛选和应用列表，审批实例则散落在具体审批型应用的运行页里。截图中暴露了两个问题：

- 左侧缺少承载跨应用管理能力的固定入口，审批状态、运行记录等不应该混入应用分类和应用排序。
- 右侧审批状态界面被放进单个应用运行表单，实例列表、详情、时间线和操作按钮拥挤在一起，用户很难判断自己是在管理某个应用，还是在处理全局审批队列。

本轮重整目标是：在应用面板分类筛选下方新增独立的“操作”区；把完整审批实例管理迁到右侧独立视图；审批型应用运行页只保留轻量摘要和跳转入口。

## 左侧入口结构

操作区固定放在应用面板顶部控制区中，位置为：

```text
搜索框
分类筛选 + 重置
操作
  - 审批状态
  - 运行记录
应用列表
```

首批操作项固定为“审批状态”和“运行记录”。这些操作项不是应用，因此不参与应用搜索结果、分类统计数量、常用应用、最近使用、应用排序、置顶、隐藏或安装状态。

点击操作项时，右侧主工作区打开对应管理视图；视觉层级与应用运行 tab 同级，但内部语义是 operation view，而不是 installed app。

## 审批实例管理

点击“审批状态”后，右侧打开“审批实例管理”。默认视图聚合所有审批型应用的审批实例，并按更新时间倒序展示。

顶部控制区包含：

- 搜索：匹配应用名、标题、实例 ID、当前节点、申请人、审批人、业务记录、远程审批 ID、结果状态等。
- 应用筛选：默认“全部应用”，可筛到某个审批型应用。
- 状态筛选：全部、待审批、已通过、已驳回、需关注、草稿。
- 刷新：重新读取全局审批实例注册表。

队列筛选保留为一组清晰的 lane：我的申请、待我审批、已处理、需关注、全部。

主体采用“列表 + 详情”结构：

- 列表显示：应用名、审批标题、当前节点、状态、更新时间、实例 ID。
- 详情显示：审批摘要、业务对象、业务记录、远程审批 ID、结果包、时间线。
- 操作按钮显示：通过、驳回、标记关注。

按钮启用规则：

- 未选择实例时，“通过”和“驳回”禁用，“标记关注”禁用。
- 实例状态为 pending 或 draft，或 lane 为 pending_my_approval 时，“通过”和“驳回”启用。
- 只要存在选中实例，“标记关注”可用。
- 操作后实例写回本地审批实例注册表，并尽可能同步到 DataSrv。

## 审批型应用运行页

报销申请等审批型应用内部不再展示完整三栏审批管理。运行页只保留轻量摘要区：

- 最近审批实例数量
- 待处理数量
- 查看全部审批状态
- 查看本应用审批

“查看全部审批状态”进入全局审批实例管理，应用筛选为“全部应用”。“查看本应用审批”进入同一个管理视图，并带入当前 appID 作为应用筛选。

审批型应用仍负责发起审批、记录 pending/completed/failed 实例、保留 workflow result、outputs、artifacts 和 DataSrv 同步信息；只是完整管理界面不再嵌在应用运行页中。

## 后端接口策略

保留现有接口：

```go
ListMaclawAppApprovalInstances(appID string, lane string, limit int)
```

该接口继续要求 appID 非空，用于兼容已有按应用读取审批实例的调用。

新增全局聚合接口：

```go
ListMaclawAppApprovalInstancesAll(lane string, limit int)
```

接口行为：

- 从本地审批实例注册表读取所有 app 的实例。
- 支持 lane 过滤。
- 默认和最大 limit 上限保持 200。
- 返回字段沿用 `maclawAppApprovalInstance`。
- 前端不再遍历每个审批型应用后自行拼接实例。

## 运行记录入口

“运行记录”首版作为独立 operation view，聚合展示本地 `maclaw:apps-run-history:v1` 中各应用最近运行记录。

首版只需要基础能力：全部应用 / 单应用筛选、最近运行记录列表、空状态、刷新。

安装记录、发布记录、发布审核记录等后续也可以进入同一个“操作”区，但不在本轮扩展。

## 迁移边界

本轮做：左侧新增操作区、新增全局审批实例管理视图、审批型应用运行页改为轻量摘要、新增全局审批实例后端接口和 Wails 绑定、运行记录提供基础聚合视图。

本轮不做：复杂运行记录筛选、安装记录、发布记录、发布审核记录、改变审批实例存储结构、改变旧的按 appID 列表接口语义、将 operation view 当作普通 app 参与安装排序或最近使用。

## 测试验收

前端验收：

- 应用面板渲染“操作”区。
- “审批状态”和“运行记录”不影响应用分类数量。
- 点击“审批状态”打开全局审批实例管理。
- 审批队列筛选、应用筛选、空状态、详情选择和审批按钮状态正确。
- 审批型应用运行页只显示轻量审批摘要和跳转入口。
- 点击“查看本应用审批”进入全局管理并带入当前应用筛选。

后端验收：

- `ListMaclawAppApprovalInstancesAll` 可跨多个 app 返回实例。
- lane 过滤生效。
- limit 生效。
- 空注册表返回空数组。
- 旧 `ListMaclawAppApprovalInstances` 仍要求 appID，兼容行为不变。

文档验收：

- 左侧入口位置明确。
- 首批操作项明确。
- 审批实例管理布局明确。
- 接口策略明确。
- 迁移边界明确。
- 截图中“左侧缺少操作入口”和“右侧审批状态混乱”两处问题都有对应处理方式。
