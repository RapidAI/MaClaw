# 高考志愿填报参考工作流设计

## 背景

新增一个面向中国大陆普通高考志愿填报的工作流模板，帮助用户基于地区、选科、性别、分数和位次检索可填报院校及专业，生成可追溯依据的填报参考资料与填报建议。

该工作流不是通用问答，也不是只输出泛泛分析报告。最终交付物必须是一份可用于填报决策的结构化建议清单，包含总排清单、冲/稳/保分档、普通类/中外合办/中外合作大学/国外高校中国校区/境外校区类型标识、往年录取位次依据、推荐理由和风险提示。

这里的“境外校区”指中国高校在国外开设或合作运营的校区/项目，例如厦门大学马来西亚分校、河北工业大学芬兰校区等。它们应纳入中外合作相关方案的检索和比较，但在输出中单独标记为 `境外校区`，避免与国内中外合办项目混淆。

这里的“中外合作大学/国外高校中国校区”指国外高校或港澳高校与中国合作方在中国境内设立的独立法人或合作办学机构/校区，例如宁波诺丁汉大学、西交利物浦大学、上海纽约大学、昆山杜克大学、香港中文大学（深圳）、北京师范大学-香港浸会大学联合国际学院、广东以色列理工学院、深圳北理莫斯科大学等。它们既不能被归为普通公办专业，也不能被“境外校区”示例替代，检索阶段必须单独覆盖。

## 目标

1. 通过 `InputSchema` 弹出结构化输入面板，收集考生填报所需信息。
2. 使用位次作为核心判断依据，分数作为辅助参考。
3. 联网检索普通类、中外合办、中外合作大学/国外高校中国校区和境外校区可报院校/专业，并记录数据来源。
4. 收集就业行业或发展方向意愿、未来规划倾向，作为专业方向选择依据。
5. 检查选科、性别、体检、语种、单科成绩、办学地点、学费等限制。
6. 按“录取可能性 + 专业质量 + 就业/发展方向适配 + 用户偏好适配 + 数据可信度”综合排序。
7. 输出总排清单，以及冲、稳、保三个分档清单。

## 非目标

首版不覆盖以下特殊招生场景：

- 艺术类、体育类
- 强基计划、综合评价、专项计划
- 港澳台及海外院校（不含中外合作大学/国外高校中国校区，也不含中国高校在国外开设或合作运营的境外校区/项目；这些类型已纳入本工作流）
- 专科批次的专门规则
- 自动填报志愿系统或直接提交志愿

这些场景后续可以扩展为独立模板或扩展字段。

## 工作流模板

建议新增模板：

```go
Type:        "gaokao_application"
Name:        "高考志愿填报参考"
Description: "考生信息采集 -> 录取数据检索 -> 候选院校专业排序 -> 冲稳保填报建议。适用于普通高考志愿填报、院校专业选择、普通类、中外合办、中外合作大学和境外校区方案对比，包括宁波诺丁汉大学、西交利物浦大学、上海纽约大学等国外高校中国校区/中外合作大学，以及厦门大学马来西亚分校、河北工业大学芬兰校区等中国高校境外校区。"
Keywords:    []string{"高考志愿", "志愿填报", "报志愿", "位次", "分数线", "中外合办", "中外合作大学", "国外高校中国校区", "境外校区", "院校专业"}
```

建议阶段：

| 阶段 ID | 名称 | ToolPolicy | NeedsConfirm | 说明 |
|---|---|---|---|---|
| `gaokao_profile` | 考生信息采集 | `ToolPolicyDocOnly` | true | 通过 `InputSchema` 弹出输入面板，生成考生画像和检索边界 |
| `gaokao_data_search` | 录取数据检索与证据整理 | `ToolPolicyFull` | true | 联网检索官方或可信来源，整理普通类、中外合办、中外合作大学/国外高校中国校区与境外校区候选数据 |
| `gaokao_candidate_ranking` | 候选院校专业排序 | `ToolPolicyFull` | true | 根据位次、专业质量、偏好和限制进行排序、分档 |
| `gaokao_final_plan` | 填报参考资料与建议 | `ToolPolicyDocOnly` | true | 输出总排清单、冲稳保清单和填报策略建议 |

`gaokao_data_search` 和 `gaokao_candidate_ranking` 必须使用 `ToolPolicyFull`，因为需要联网检索和必要的数据核验。

## 输入面板

第一阶段必须通过 `InputSchema` 弹出结构化表单。位次、地区、选科和性别为关键必填项。

建议字段：

| 字段名 | 标签 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `province` | 地区/省份 | select | 是 | 固定下拉：北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、上海、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、广西、海南、重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆 |
| `exam_year` | 高考年份 | text/number | 是 | 默认为当前年份，可由用户修改 |
| `subject_type` | 选科类型 | text/select | 是 | 支持文科、理科、物化生、物化地、史政地等 |
| `province_admission_mode` | 省份录取规则模式 | select | 否 | 自动判断、新高考专业组模式、院校专业组模式、专业+院校模式、传统文理模式 |
| `gender` | 性别 | select | 是 | 男、女；用于检查专业性别限制 |
| `score` | 分数 | number | 否 | 辅助参考 |
| `rank` | 位次 | number | 是 | 核心判断依据 |
| `batch` | 批次 | select/text | 否 | 本科批、本科一批、本科二批等 |
| `preferred_majors` | 偏好专业 | textarea | 否 | 多个专业可换行输入 |
| `career_intent` | 就业行业或发展方向意愿 | textarea | 否 | 如互联网/AI、芯片半导体、金融、医疗健康、教师、公务员、考研深造、出国、暂不明确 |
| `future_plan` | 未来规划倾向 | select | 否 | 就业优先、考研/保研优先、出国深造、考公/事业编、暂不明确 |
| `excluded_majors` | 排除专业 | textarea | 否 | 不接受的专业 |
| `preferred_locations` | 偏好城市/地区 | textarea | 否 | 如：长三角、北京、成都、广州 |
| `accept_joint_program` | 是否接受中外合办/中外合作大学/境外校区 | select | 是 | 接受、不接受、可作为备选 |
| `tuition_limit` | 学费上限 | text/number | 否 | 对中外合办尤其重要 |
| `strategy` | 填报策略 | select | 否 | 优先专业、优先学校、均衡 |
| `notes` | 补充说明 | textarea | 否 | 家庭偏好、就业方向、读研计划等 |

性别字段必须进入 prompt，并在后续阶段用于检查军警、航海、定向、护理、助产等可能存在性别限制或建议性要求的专业。

`career_intent` 和 `future_plan` 不作为硬性筛选条件，而作为专业方向排序依据。若用户未填写或填写“暂不明确”，应优先推荐专业口径较宽、未来转向空间较大的方案，并在最终建议中提示方向仍需进一步确认。

## 数据来源要求

检索阶段必须优先使用以下来源：

1. 省级教育考试院、招生考试院、官方志愿填报系统公开信息。
2. 阳光高考等教育部相关平台。
3. 院校本科招生网、招生章程、历年录取分数/位次表。
4. 院校官方发布的专业组、招生计划、办学地点、学费和专业备注。
5. 中外合作大学、国外高校在中国设立或合作运营的校区/机构、以及中国高校境外校区或境外合作办学项目官方网站；必须显式检索宁波诺丁汉大学、西交利物浦大学、上海纽约大学、昆山杜克大学、香港中文大学（深圳）、北京师范大学-香港浸会大学联合国际学院、广东以色列理工学院、深圳北理莫斯科大学等国内中外合作大学/国外高校中国校区，以及厦门大学马来西亚分校、河北工业大学芬兰校区等中国高校境外校区。

允许使用第三方聚合站作为线索，但不能把第三方数据作为唯一强依据。若只能找到第三方来源，必须在输出中标记为“待官方复核”。

每条推荐必须尽量记录：

- 来源名称
- 来源 URL
- 数据年份
- 最低分
- 最低位次
- 专业或专业组名称
- 类型：普通 / 中外合办 / 中外合作大学 / 国外高校中国校区 / 境外校区

没有年份、来源 URL 或最低位次的数据，不能作为强推荐依据，只能进入“待核验/补充资料”说明。

所有信息都必须有来源。专业质量、就业/升学路径、行业适配、限制风险、录取概率、数据可信度、学费风险等判断也必须说明依据来源；缺来源时只能标注“待核验/无法判断”，不得脑补，也不得用经验判断替代来源。

## 专业限制检查

检索和排序阶段必须检查并输出限制/风险提示，包括但不限于：

- 性别限制或性别建议
- 选科要求
- 色盲、色弱、身高、视力等体检要求
- 外语语种限制
- 单科成绩要求
- 校区/办学地点差异
- 中外合办/中外合作大学/国外高校中国校区学费、培养模式、是否可转专业
- 境外校区的境外学习地点、签证/出入境、语言环境、住宿生活成本、学历认证等风险
- 专业名称相近但培养方向不同的情况

若来源没有明确说明，不得断言“无限制”。应标记为：

```text
未见明确限制，填报前需以当年招生计划和招生章程为准
```

## 排序规则

最终排序以“最值得优先考虑”为目标，而不是简单按最低位次排序。

建议综合评分因素：

| 因素 | 权重倾向 | 说明 |
|---|---|---|
| 录取可能性 | 高 | 用户位次与往年最低位次的差值，多年趋势优先 |
| 专业质量 | 高 | 专业实力、院校层次、学科口碑、就业/升学适配 |
| 就业/发展方向适配 | 高 | 与用户就业行业意愿、未来规划倾向的匹配度 |
| 用户偏好 | 中 | 专业、城市、学费、是否接受中外合办/中外合作大学/国外高校中国校区/境外校区 |
| 风险限制 | 高 | 性别、选科、体检、语种、单科成绩等限制会降权或剔除 |
| 数据可信度 | 高 | 官方、多年、专业级位次数据优先 |

分档建议：

- **冲**：用户位次略低于或接近往年最低位次，存在机会但风险较高。
- **稳**：用户位次与往年最低位次匹配度较高，录取概率相对合理。
- **保**：用户位次明显优于往年最低位次，用作兜底，同时专业可接受。

分档阈值不要硬编码为全国统一比例。不同省份、批次、专业热度差异大，应由 LLM 基于数据质量和位次差解释分档原因。

## 最终输出格式

最终阶段必须输出四个主块：

1. 总排清单
2. 冲
3. 稳
4. 保

总排清单按综合推荐顺序混排普通类、中外合办、中外合作大学/国外高校中国校区和境外校区，但必须保留 `类型` 字段。

推荐表字段：

| 字段 | 说明 |
|---|---|
| 推荐序号 | 按综合推荐顺序排序 |
| 学校 | 院校名称 |
| 专业/专业组 | 专业名称、专业组或招生方向 |
| 办学地点 | 校区、城市、中外合办办学地点、国外高校中国校区或境外校区地点 |
| 类型 | 普通 / 中外合办 / 中外合作大学 / 国外高校中国校区 / 境外校区 |
| 往年最低位次 | 尽量使用专业或专业组最低位次 |
| 近三年位次趋势 | 上升、下降、波动或数据不足，降低单年误判 |
| 年份 | 数据年份 |
| 与考生位次差 | 用户位次相对最低位次的差值 |
| 档位 | 冲 / 稳 / 保 |
| 录取概率标识 | 高 / 中 / 低 / 待核验 |
| 数据可信度标识 | 高 / 中 / 低 / 待核验 |
| 学费风险标识 | 低 / 中 / 高 / 待核验 |
| 就业/发展方向适配 | 说明专业与用户行业意愿、就业/升学/考公等规划的匹配关系 |
| 推荐理由 | 录取可能性、专业质量、偏好适配 |
| 限制/风险提示 | 性别、选科、体检、语种、学费等 |
| 数据来源 | 来源名称和 URL |
| 依据来源 | 逐项列出录取数据、专业质量、就业/发展方向适配、限制风险、学费风险等判断对应的来源；缺来源必须标注待核验 |

输出示例结构：

```markdown
## 总排清单

| 序号 | 学校 | 专业/专业组 | 办学地点 | 类型 | 往年最低位次 | 近三年位次趋势 | 年份 | 位次差 | 档位 | 录取概率 | 数据可信度 | 学费风险 | 就业/发展方向适配 | 推荐理由 | 限制/风险提示 | 数据来源 | 依据来源 |
|---|---|---|---|---|---:|---|---|---:|---|---|---|---|---|---|---|---|---|

## 冲

...

## 稳

...

## 保

...

## 填报策略建议

1. 冲稳保比例建议
2. 普通类、中外合办、中外合作大学/国外高校中国校区与境外校区取舍建议
3. 专业优先/学校优先策略，以及结合就业行业意愿和未来规划倾向的专业取舍建议
4. 必须在正式填报前复核的事项
```

## Prompt 约束

阶段指令必须包含以下硬约束：

1. 以位次为核心判断依据，分数只作辅助。
2. 必须区分普通类、中外合办、中外合作大学/国外高校中国校区与境外校区。
   - 中外合作大学/国外高校中国校区包括宁波诺丁汉大学、西交利物浦大学、上海纽约大学、昆山杜克大学、香港中文大学（深圳）、北京师范大学-香港浸会大学联合国际学院、广东以色列理工学院、深圳北理莫斯科大学等。
   - 境外校区包括中国高校在国外开设或合作运营的校区/项目，例如厦门大学马来西亚分校、河北工业大学芬兰校区等。
3. 必须把就业行业或发展方向意愿、未来规划倾向作为专业排序依据，但不能作为唯一硬筛条件。
4. 必须结合省份录取规则模式检查比较口径，避免把院校专业组、专业+院校、传统文理混为一谈。
5. 必须检查性别、选科、体检、语种、单科成绩、学费、办学地点等限制。
6. 所有事实性信息和关键判断都必须给出来源，尤其是往年最低位次、招生限制、专业质量、就业/发展方向适配、学费风险、中外合作大学/国外高校中国校区和境外校区信息；缺来源必须标注待核验。
7. 必须整理结构化缓存候选记录。
8. 不得编造学校、专业、位次、学费、招生章程内容、专业实力、就业方向或任何数据来源。
9. 数据不足或判断依据不足时必须标记“待核验/无法判断”，不能强行推荐。
10. 最终输出必须包含总排清单和冲/稳/保三档，并为每条推荐给出录取概率、数据可信度、学费风险标识和依据来源。

   - 判断也要溯源
   - 禁止编造
7. 最终阶段 prompt 要求输出总排清单、冲、稳、保和填报策略建议。

## 已实现扩展能力

1. 省份级规则配置：输入面板提供 `province_admission_mode`，支持自动判断、新高考专业组、院校专业组、专业+院校、传统文理模式。
2. 结构化数据缓存候选记录：检索阶段必须输出 province、school、major_or_group、min_ranks、source_url、verification_status 等稳定字段，供后续沉淀官方录取位次表。
3. 多年趋势分析：候选排序必须优先使用近三年位次序列，标记上升、下降、波动或数据不足。
4. 可视化风险标识：最终清单必须包含录取概率、数据可信度、学费风险三个标识。
5. 用户历史偏好记忆：地区、录取规则、性别、偏好专业、就业方向、未来规划、排除专业、偏好城市、是否接受中外合办/中外合作大学/国外高校中国校区/境外校区、学费上限、填报策略字段标记为 Reusable，可复用历史偏好。
