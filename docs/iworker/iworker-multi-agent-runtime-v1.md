### GUI 配置闭环

iWorker GUI 侧已暴露 `SaveIWorkerCenterConfig`、`IWorkerCenterConfigStatus`、`StartIWorkerGoalWatch`、`StopIWorkerGoalWatch`、`IWorkerGoalWatchStatus`、`RunIWorkerGoalWatchOnce` 绑定。保存 iWorkerCenter 配置时会写入独立 Center 字段，并根据 `auto_start` 选择是否立即重建并启动本地 GoalWatch watcher。配置不完整时 watcher 会保持停止，避免误连 Hub / HubCenter 或把本地电脑变成事实源。
