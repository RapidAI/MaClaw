# 已回答问题答案缓存

## 目标

对已回答的独立问题复用安全答案。默认有效期为 0 天，即不缓存；用户可在“设置 → IM → 蓝信 → 蓝信机器人”的**当前机器人实例**编辑器中开启缓存，并将有效期设为 1–365 天以启用复用，或设回 0 天关闭复用。缓存策略按机器人实例分别保存；缓存结果仍按机器人隔离，群聊再按群组隔离。

## 命中与隔离

- 先精确匹配规范化后的问题文本；精确未命中时，可在**同一机器人、同一会话范围、同一语言、同一专家/提示词/目录权限及同一模型策略**内进行本地、严格的近似语义匹配。近似匹配不调用 LLM 或外部向量服务：英文仅归一化词形变化，中文仅归一化问句尾部并比较关键词/字符片段，只接受唯一且高置信度的候选；候选分数接近、范围不同或置信度不足时一律重新生成，绝不猜测复用。
- 缓存条目保存规范化问题和不含用户标识的范围指纹，仅用于上述受限检索；问题元数据有长度上限，超长独立问题仍可按哈希精确命中，但不会进入近似检索，避免把超长输入变成长期共享存储内容。旧版本没有这两个字段的条目同样仍可精确命中，但不会参与近似匹配，直到自然过期或重新生成。
- 缓存键包含平台、机器人 Profile、会话范围（私聊或具体群聊）、有效回复语言、完整的 AI 绑定快照，以及群聊可影响回答的非敏感权限策略（知识库来源、联网和目录授权）。同一机器人同一会话范围内，不同用户的相同独立问题可命中同一安全答案，以提升响应效率；群聊的动态成员元数据不参与问题匹配。仅无既有会话上下文的独立问题可跨用户复用，避免将某位用户的上下文相关回答带给另一位用户。专家名称同样会注入系统提示词，故名称、提示词或工具/技能策略更新后，旧答案不会复用；图标、卡片描述和更新时间等展示元数据不影响命中。
- 对通用助手，缓存键还包含全局角色名称/说明及当前模型行为配置（基础 Provider 标识、模型、协议、推理与思考模式、辅助模型、按任务模型路由和成本路由模式），不包含任何密钥；角色或模型行为调整后会重新生成答案。
- 绑定快照在消息入队前完成校验与深拷贝；即使网关侧随后复用或修改消息对象，排队中的这一轮仍按入队时的权限与缓存键处理。
- 不同机器人、私聊/群聊会话范围或不同专家边界不会共享答案；同一范围内的不同用户可复用无上下文依赖的安全答案。
- 过期条目在读取时立即失效，不会再被返回；缩短有效期会立即限制已有条目，延长有效期也不会延长已有条目原先的到期时间。下次写入时会统一清理并原子化写回 `<data>/answer_cache/answers.json`。

## 绕过与写入规则

以下请求始终重新生成：更新/最新/刷新/重新生成等时效请求，追问，附件，斜杠命令，工作流、确认（包括确认后的改写或直连执行）和后台任务。用户明确表示答案不满意、错误、不准确、无帮助，或要求重新回答、换一种说法、更准确/更详细/更好的回答时，也会直接绕过精确和近似缓存。活动工作流、待选工作流、工作流文档评审、录音后处理、`ask_user`、待答复以及模板子代理等会话状态也不读取缓存；即使模板子代理尚未进入工作流 Agent loop，只要已处于待执行状态也会绕过。

群聊中带有引用消息、人员提及或其他额外提示上下文的请求也会绕过缓存，确保回答不会脱离其引用线程。蓝信请求必须携带网关从原始消息中提取并验证过的独立问题文本；缺少该标记的装饰提示不会进入缓存。

涉及提问者身份或个人数据的问题（例如“我的订单”“我的账号”“我是谁”）同样始终重新生成，不参与跨用户复用。

只有成功的纯文本 Agent 回答会写入缓存。工具调用、文件、图片、语音、错误、确认卡片、动作和延迟响应均不会被缓存。

缓存命中仍会写入该机器人的会话历史，保证后续正常追问拥有完整上下文；但不会再次运行追问识别、语义提取或其他可能调用模型的会后任务。
