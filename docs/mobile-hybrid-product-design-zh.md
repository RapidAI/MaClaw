# MaClaw Mobile 混合产品设计（索引）

完整设计见：

**[mobile/maclaw_mobile/docs/mobile_hybrid_product_design_zh.md](../mobile/maclaw_mobile/docs/mobile_hybrid_product_design_zh.md)**

摘要：

- 短任务在手机交互闭环，长任务在 Hub/后台  
- 底栏：AI助手（或数字分身）/ 后台 / 数字员工 / 我的  
- **Hub 官方 Mobile = 完整 Agent（Skill / MCP / 权限，对齐 GUI）**；手机只做控制面  
- 文档不占一级 Tab；查看在手机，修改在 Hub；默认 100MB 配额  
- 未开通官方服务时第一栏走自己的数字分身；离线引导授权卡或开电脑  
- 免费仅自己的数字员工；Hub 数据按 tenant→user 隔离
