第三方接入协议

先握手协商能力，再安全传输消息与媒体

IM Gateway v1.1

HTTP + JSON 的消息通道，支持文本、音频、图片、文件、长轮询和服务端媒体 URL。

阅读协议要点 →

Device Gateway

设备配对、持久 Token、宠物状态、环境数据和媒体能力协商，适用于硬件终端。

查看设备接入 →

Agent Client Protocol

让 VS Code、Zed、JetBrains 等编辑器以标准 Agent 协议连接 MaClaw。

阅读 ACP 设计 →
安全提示：公网部署请使用 HTTPS；Token 仅通过 Authorization 传输；媒体下载使用 MaClaw 生成的受保护 URL，不要让服务端抓取第三方回调地址。

如何通过开发获得收益

透明的 Credits 结算与资产权益

免费分发扩大使用量和评分，积累下载、收藏与社区信誉。
买断收费为 Skill Suite、宠物包或专家设定价格，用户购买后获得版本权益。
持续维护发布新版本、修复问题并参与创作者榜，按平台规则获得结算。
发布前请确认资源版权、依赖声明和隐私边界；价格变更应发布新版本，下架不会撤销已购用户的下载权益。
