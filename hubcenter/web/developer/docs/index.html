Skill / Suite 开发

Skill 是可独立执行和安装的能力单元；Suite 是多个关联 Skill 的发布与分发单位。两者均需要稳定 ID、版本、来源和完整性校验。

最小目录

my-skill/
  skill.yaml
  SKILL.md
  scripts/              # 可选：受约束的辅助脚本
  tests/                # 推荐：本地验证用例

发布检查

  • 使用小写 slug 作为稳定 ID，版本遵循 SemVer。
  • 声明输入、输出、依赖、权限和网络边界；拒绝路径穿越与符号链接。
  • Suite 额外提供 suite.yaml，成员 Skill 保持可独立安装。

宠物包 3.0

宠物包是纯声明式资源包，禁止 JavaScript、WASM、可执行程序和远程地址。渲染降级链固定为 native-character → native-skeleton → native/idle.png。

三种 renderer

  • native-raster：静态状态帧，适合快速发布。
  • native-skeleton：骨骼动作，需要 rig JSON、贴图白名单和 idle 回退。
  • native-character：状态机、表情和事件表演，使用 schema 3。

最小 manifest

schema_version: 3
id: my-character
version: 1.0.0
renderer: native-character
assets:
  preview: preview.png
  native:
    idle: native/idle.png
capabilities:
  pet_performance_v3: true

AI 专家开发

AI 专家由提示词、工具、Skill、模型策略和安全约束组成。发布时将配置固化为版本快照，审核通过后才能进入专家市场。

建议流程

  • 定义专家目标、适用场景和不应处理的请求。
  • 为每个工具声明参数、权限、失败回退和敏感数据处理。
  • 使用真实任务样例验证输出质量、成本和越权边界，再提交市场审核。

第三方接入协议

第三方客户端始终主动通过 HTTP 连接 MaClaw。公网部署使用 HTTPS，正常请求使用持久 Gateway Token。

启动顺序

1. GET  /api/im-gateway/v1/health
2. POST /api/im-gateway/v1/handshake
3. POST /api/im-gateway/v1/incoming
4. GET  /api/im-gateway/v1/outgoing?cursor=...
5. POST /api/im-gateway/v1/ack

能力协商

在 handshake 中声明 input/output modalities、音频参数、媒体 deliveryModes、petStates 和工具能力。未声明的输出形式一律视为不支持。媒体大文件使用服务端生成的受保护 URL，不提供第三方回调地址。

设备配对

POST /api/device-gateway/v1/pair
{"clientId":"device-001","pairCode":"645432"}

组件组合方法

复杂产品可以由多个受控组件组合，不必把所有逻辑塞进一个包中。

  • MCP 能力：把外部服务封装为清晰的 tools/list、tools/call 接口，声明 endpoint、鉴权和运行时健康检查。
  • 桌面插件：负责界面或本地资源，使用最小权限与明确的生命周期；核心能力仍放在 Skill 或专家配置中。
  • 设备适配器：通过 Device Gateway 传输状态和媒体，设备密钥不进入 Skill 包或专家提示词。
  • Suite / 专家组合：用稳定 ID 和版本锁定成员，升级时保留可回滚的完整清单。

发布与收益

统一流程：本地验证 → 提交审核 → 市场上架 → 用户获取 → Credits 结算。免费发布用于积累下载与信誉；买断发布按平台规则结算。

  • 价格变更作为新版本发布；下架不会撤销已购用户的下载权益。
  • 发布者必须拥有资源版权，并如实披露依赖、权限和隐私处理。
  • 发现安全或版权问题时，平台可暂停分发并保留审计记录。

ACP 客户端接入

编辑器或 IDE 作为 ACP client，通过本地或远程 transport 创建 session、发送 prompt、接收增量事件，并在需要时处理权限请求。实现时保持 session 与 workspace 隔离，声明支持的 tool 能力，断线后使用 request id 做幂等恢复。

{"method":"session/create","params":{"workspace":"/project","capabilities":{"tools":true,"streaming":true}}}
{"method":"session/prompt","params":{"sessionId":"sess_123","text":"运行测试并总结失败项"}}
