Hub Center

MaClaw 部署中枢 · 控制平面

Hub Center 是 MaClaw 生态的中枢控制平面：负责节点注册与发现、路由解析、策略与安全治理、能力市场与积分计费。它把分散在各处的 MaClaw 客户端与 Hub 节点组织成一张可治理、可运营、可扩展的企业级网络。

Hub Center Features

Hub Center 功能描述

从节点接入到能力分发、从策略治理到积分计费，Hub Center 为整个 MaClaw 网络提供统一的中枢服务。

节点注册与发现

Hub 节点向 Hub Center 注册并保持心跳，管理员在后台统一查看节点运行时状态、版本与容量，新节点接入即被自动发现。

智能路由解析

集中维护「客户端 → Hub 节点」的路由表，邀请码与账号归属实时可查；节点扩缩容、迁移与故障切换对客户端透明。

策略与安全治理

封禁邮箱 / IP、消息与评论审核、LLM 内容策略集中配置；管理动作全程留痕，治理策略即时下发到全网节点。

能力与专家市场

运营 SkillHub 能力市场与专家市场：能力包上架审核、付费分发、专家入驻与订单交付，形成完整的能力生态。

积分与计费

统一积分账务：充值、消费、分成、提现与退款负债全流程记账；Token 银行与流水可审计，支撑商业闭环。

高可用与运维

多节点 HA 集群数据实时同步，单节点故障不影响服务；消息公告、故障日志、路由诊断等运维工具开箱即用。

About MaClaw

MaClaw 简介

Hub Center 治理之下的终端，是一个真正懂你业务的 AI 助手客户端。

"AI 不应只是一问一答的助手，而应成为真正懂你业务、守你规则、记得你过往的数字员工。"

MaClaw 是跨平台的 AI 助手客户端，把对话、技能（Skill）、MCP 工具、记忆与知识放进同一个工作台。它既可以是企业统一推送能力的「数字员工」，也可以是数据主权完全属于个人的私有 AI 伙伴——所有能力可治理、可审计、可撤销。

跨平台客户端

Windows / macOS / Linux 桌面端与命令行、移动端全覆盖，一套体验随处可用。

一体化工作台

对话、任务、技能与 MCP 工具、组织记忆与知识库在同一界面内协同。

多模态能力

语音、图像、文档与长上下文原生支持，从会议纪要到产线巡检都能承接。

企业级治理

能力包可推送、可编排、可撤销；策略贯穿每一次调用，数据留在自有节点。
